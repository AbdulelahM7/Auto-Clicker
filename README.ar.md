# Auto Clicker

أداة نقر تلقائي خفيفة بوضع داكن لنظام ويندوز، فيها **وضع ضربات ماين كرافت (Java)** الذي يضبط توقيت كل ضربة حسب سرعة سلاحك.

## المميزات

- اختيار زر الفأرة: يسار أو وسط أو يمين
- **الفاصل الزمني** بالمللي ثانية، مع **تحديد عدد النقرات** (الصفر = بلا حد)
- خيار **النقر المزدوج**
- **تأخير عشوائي** إضافي لتنويع التوقيت
- **عداد مباشر** مع مدة التشغيل وعدد النقرات في الثانية
- **مفتاح بدء/إيقاف عام** (الافتراضي `F6`) يعمل من أي نافذة، ويمكن **تغييره** من تبويب *Options*
- **وضع ماين كرافت**: اختر سلاحك ويُضبط الفاصل تلقائياً (التفاصيل أدناه)
- **إيقاف أمان بالزاوية**: حرّك المؤشر إلى أعلى يسار الشاشة فيتوقف النقر فوراً
- خيار **Always on top**، والإعدادات **تُحفظ تلقائياً**
- توقيت دقيق بلا انحراف مع دقة 1 مللي ثانية على ويندوز، فتبقى الفواصل القصيرة دقيقة
- تحقق من المدخلات مع رسائل واضحة، والأخطاء تُسجَّل بدل أن يتعطل البرنامج

## التحميل

حمّل آخر إصدار من صفحة **[Releases](../../releases/latest)**:

| الملف | الوصف |
|---|---|
| `AutoClicker-Setup-x.y.z.exe` | ملف تثبيت (قائمة ابدأ، واختصار سطح المكتب اختياري، وإلغاء تثبيت). لا يحتاج صلاحيات مسؤول. |
| `AutoClicker-portable-x.y.z.exe` | ملف واحد بدون تثبيت. |
| `SHA256SUMS.txt` | بصمات الملفات للتحقق من سلامة التحميل. |

> **SmartScreen ومضادات الفيروسات:** الملفات غير موقّعة رقمياً، فقد يعرض ويندوز رسالة *"Windows protected your PC"*. اضغط **More info ثم Run anyway**. وبعض مضادات الفيروسات تنبّه على أي برنامج يسجّل التقاط عام للوحة المفاتيح (وهو لازم لاكتشاف مفتاح البدء/الإيقاف). الكود المصدري كامل في هذا المستودع، فتقدر تقرأه أو [تبنيه بنفسك](#البناء-من-المصدر).

## الاستخدام

1. ضع المؤشر فوق العنصر الذي تريد النقر عليه.
2. اضغط **F6** للبدء، واضغطه مرة ثانية للإيقاف. (زر **Start** في النافذة يبدأ بعد مهلة قصيرة لتحرك المؤشر بعيداً عن الزر، ويمكن تعديل المهلة من *Options*.)
3. لتغيير المفتاح: افتح **Options**، اضغط على مربع المفتاح، ثم اضغط المفتاح الجديد. مفتاح `Esc` يلغي.

نصيحة: مفاتيح F أنسب خيار. الحرف العادي سيشغّل البرنامج أيضاً أثناء كتابتك في برامج أخرى.

## وضع ماين كرافت

في **ماين كرافت Java**، يقل ضرر السلاح (وتختفي الضربات الحرجة وضربات الاكتساح) إذا ضربت قبل اكتمال شحن السلاح. فالنقر الأسرع من اللازم يضيّع الضربات فقط.

فعّل **Minecraft hit** واختر سلاحك. يُحسب الفاصل لضربة مشحونة بالكامل، وتُقفل بقية إعدادات النقر (تصير رمادية). وعند إطفائه ترجع إعداداتك كما تركتها.

الشحن الكامل يأخذ `20 ÷ سرعة الهجوم` تيك (التيك = 50 مللي ثانية). يُقرَّب الفاصل لأقرب تيك كامل للأعلى، ثم يُضاف هامش أمان 10 مللي ثانية:

| السلاح | سرعة الهجوم | الفاصل |
|---|---|---|
| سيف (كل الأنواع) | 1.6 | 660 ms |
| فأس: خشب / حجر / نحاس | 0.8 | 1260 ms |
| فأس: حديد | 0.9 | 1160 ms |
| فأس: ذهب / ألماس / نذرايت | 1.0 | 1010 ms |
| رمح ثلاثي (Trident) | 1.1 | 960 ms |
| صولجان (Mace) | 0.6 | 1710 ms |
| يد فارغة | 4.0 | 260 ms |

ملاحظات:
- **نسخة Java فقط.** نسخة Bedrock ما فيها شحن للضربات.
- أدوات أخرى (فأس التعدين، المجرفة، المعزقة، الرماح) لها سرعات مختلفة وليست مضافة حالياً. استخدم الوضع العادي بفاصل تحدده أنت.
- اللعبة تعالج الإدخال مرة كل تيك، فقد تختلف النتيجة بمقدار تيك واحد (50 مللي ثانية).

## البناء من المصدر

يتطلب ويندوز وبايثون 3.9 أو أحدث (مشغّل `py`).

```powershell
git clone https://github.com/E7TRAF702/auto-clicker.git
cd auto-clicker
py -m pip install -r requirements.txt
py auto_clicker.py
```

### بناء ملف exe وملف التثبيت

```powershell
build.bat
```

الناتج:

- `dist-portable\AutoClicker-portable.exe`: ملف exe واحد
- `dist-installer\AutoClicker-Setup-<version>.exe`: ملف التثبيت، يُبنى بـ [Inno Setup 6](https://jrsoftware.org/isdl.php) (يُتخطى إذا لم يكن مثبتاً)

غيّر رقم الإصدار في أعلى `build.bat` وفي `installer/AutoClicker.iss` (أو مرّر `/DAppVersion=...`).

### نشر إصدار (GitHub Actions)

دفع وسم إصدار يبني كل شيء على GitHub ويرفق الملفات بإصدار جديد:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

## الإعدادات والسجلات

تُحفظ في `%APPDATA%\AutoClicker\`:

- `settings.json`: إعداداتك (احذفه لإعادة الضبط)
- `error.log`: تفاصيل الأخطاء إن حصلت

## الخصوصية

كل شيء يعمل محلياً على جهازك. البرنامج لا يتصل بالإنترنت ولا يجمع أي بيانات. يستمع للوحة المفاتيح فقط ليكتشف مفتاح البدء/الإيقاف، ولا يسجّل ولا يخزّن شيئاً.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| النقر لا يعمل في بعض النوافذ | ويندوز يمنع الإدخال إلى البرامج التي تعمل بصلاحيات المسؤول. شغّل Auto Clicker كمسؤول أيضاً. |
| يتوقف النقر فوراً | المؤشر في زاوية أعلى اليسار (إيقاف الأمان). حرّكه أو عطّل الخيار. |
| المفتاح لا يستجيب | قد يكون برنامج آخر يستخدم نفس المفتاح. اختر مفتاحاً آخر من *Options*. |
| الفواصل القصيرة جداً تفوّت نقرات | بعض البرامج لا تستطيع معالجة الإدخال بهذه السرعة. جرّب فاصلاً أطول. |

ماك ولينكس: الكود مبني على مكتبات متعددة المنصات وقد يعمل، لكنه مطوّر ومجرَّب لويندوز فقط. وعلى ماك يجب منح التطبيق إذن Accessibility.
